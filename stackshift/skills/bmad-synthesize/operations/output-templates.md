# Output Templates

Templates for the 4 BMAD artifacts generated by bmad-synthesize. Each artifact includes YAML frontmatter for traceability.

---

## Artifact Frontmatter

Every artifact includes this YAML frontmatter. Populate all fields dynamically.

```yaml
---
workflowType: prd  # one of: prd, architecture, epics, ux-design
project_name: "<from state file or repo name>"
date: "<current date ISO 8601>"
synthesize_mode: "yolo"  # one of: yolo, guided, interactive
inputDocuments:
  - docs/reverse-engineering/functional-specification.md
  - docs/reverse-engineering/business-context.md
  # ... list every source doc that provided content to this artifact
coverage_score: 92  # integer 0-100: percentage of sections filled from docs (not inferred)
---
```
